WristOrder architecture

The cashier speaks to a Vexo bracelet, Gemini turns speech into an order, the customer pays by scanning a Stripe QR code, and every paid order feeds the owner's dashboard and weekly restock report.

One order, start to finish

  1. Cashier speaksHolds the bracelet button: "Two large oat lattes and a croissant."
  2. Deepgram hears, Gemini parsesDeepgram turns the clip into text, primed with menu names. Gemini turns the text into tool calls like add_item.
  3. Order updates liveorder.js changes and the customer screen updates over SSE.
  4. Read-backA Deepgram Aura voice speaks the order and total. The cashier can edit by voice.
  5. "Confirm"A Stripe Checkout session is created and its QR code appears on the customer screen.
  6. Customer paysThey scan and pay on their phone. The server sees it paid within about 2 seconds.
  7. Ticket + recordThe kitchen screen gets a ticket and the order is saved to SQLite for the owner's stats.
